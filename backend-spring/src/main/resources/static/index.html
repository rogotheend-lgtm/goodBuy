소비 분석 API 테스트

계좌 거래내역 이미지를 전송하고 Spring의 OCR 연결, 소비 분류와 이상치 상세 출력이 제대로 작동하는지 한 화면에서 확인합니다.

💡
테스트 안내
기본 설정인 OCR_MODE=mock에서는 어떤 이미지를 올려도 정해진 샘플 10건이 반환됩니다. 실제 이미지 OCR은 Python 서버를 실행하고 OCR_MODE=python으로 Spring을 시작해야 합니다.
이미지 미리보기 PNG 또는 JPEG 거래내역 이미지를 1~5장 선택하세요.

새 분석 요청

POST /api/v1/analyses 한 번으로 OCR, 분류, 이상치 결과를 바로 받습니다.
