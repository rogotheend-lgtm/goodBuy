Backend API 한눈에 보기

현재 구현된 API와 서비스 간 호출을 한 줄씩 정리했습니다.

Swagger에서 테스트 이미지 분석 화면 OpenAPI JSON

Frontend → Spring

외부 API 1개
  • POST /api/v1/analyses

    이미지 1~5장과 계좌 소유자 이름을 받아 OCR·분류하고, 요청 기록을 남기지 않은 채 결과를 즉시 반환합니다.

Spring → Python

내부 호출 1개
  • POST /ocr/extraction

    이미지를 Python OCR에 전달하고 거래 대상과 금액을 받습니다.

Spring → Supabase

읽기 전용 쿼리 1개
  • SELECT categories LEFT JOIN category_rules

    카테고리명·키워드·이상치 기준·GIF 주소를 조회합니다. DB 장애 시 내장 기본값으로 즉시 분석을 계속합니다.

System

상태 확인 1개
  • GET /actuator/health

    Spring 애플리케이션의 실행 상태를 확인합니다.

전체 흐름

Frontend → Spring → Python OCR → DB 우선·기본 카탈로그 대체 → 분류·이상치·최대 비중 GIF 계산 → Frontend 즉시 응답

현재 OCR_MODE=mock에서는 샘플 거래 10건을 반환하며, 실제 OCR은 Python 서버 연결 후 동작합니다.
